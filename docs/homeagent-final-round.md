# HomeAgent / ReTask 第二轮改版说明

最新交互与技术 Demo 以末尾补充为准：两套交互原型改为一次设定后自主执行，技术 Demo 提供固定轨迹三维场景与局部物理计算，取代早期逐步确认流程及技术 Demo 占位。

本轮按第二轮待办增量修改，保留概览布局、既有导航、背景、字体与色板。新增的“查看项目文档”位于概览正文的问题定义区域，跳转至全部五份成果卡片；每份文档仍只有一个正文入口。

## 页面与交互

- **项目概览**：同步床边取书故事；计数改为“5 份研究与设计成果”，分类筛选保留。
- **HomeAgent 产品设计**：主场景改为休息时从客厅取书、交付到床边安全区。解释替代办法、价值假设和适用边界。嵌入可点击原型：选择物品与终点 → 确认授权 → 四阶段取送 → 等待用户确认 → 完成。支持物品不在位、交付区占用，以及原阶段重试、取消和转人工。
- **ReTask 产品设计**：嵌入 A 运行 → 请求 B → 前置检查 → 安全退出 → 迁移 → 配置 → 校准 → B 就绪 → 授权运行的原型。缺少字段、切换权限、B 可用性或配置确认时阻止继续；校准失败不能进入运行，恢复后必须重新检查。支持安全停止及重置。
- **关键决策**：在 ToB 转向之后、仓储场景细化之前补制造/仓储/零售服务对比，说明选择标准与可能否定移动方案的条件。未新增市场规模、客户研究结果或 ROI 结论。
- **产品说明与页脚**：删除两份产品说明正文的重复一级标题。两份说明后续按用户要求删除研究与验证计划章节，将商业模式和竞品研究合并至后部；产品定义与任务边界保留。页脚改为简洁版权信息。

## 保留的占位与限制

两个技术 Demo 仍为“规划中”；独立 ReTask 跨工位切换 PRD 页面已删除，不再单独编写；相关内容由产品设计原型与完整产品说明承载。交互原型完全由本地前端状态驱动，未连接机器人、视觉系统、产线或后端，不代表真实部署与已验证需求。刷新、重新进入页面或重置后恢复初始状态，不保存用户数据。

## 自主执行与独立中控目的（2026-10-13）

- HomeAgent 的独立中控机箱服务于三个目的：卸载机器人本地计算；统一处理和存储所有授权智能终端的数据与用户习惯；将高算力机箱及散热噪声移离机器人，可部署于墙体中或房屋外。产品设计页新增三项说明，形态图注、产品说明及架构图同步更新。本体保留实时感知、运动控制与独立安全链路。
- 两套原型直接进入任务设定页，提供预设任务与一次提交入口。用户只参与最初设定，后续阶段由组件挂载期间的模拟时钟自动推进；卸载时清除计时器，停止、异常或重置后时钟不会继续执行旧任务。
- HomeAgent：一次提交后自主取书、运送、放置验证并通知完成；移除逐步推进、二次授权与收货确认。物品不在位或交付区占用时自动结束本次执行并报告失败阶段，不把异常计为成功。
- ReTask：一次提交授权切换及检查通过后的启动；系统自主检查权限与工位可用性、安全退出 A、迁移至 B、加载已登记配置、校准与启动 B。工位不可用时拒绝切换；校准失败时安全停止并报告原因，B 不启动。移除执行链中的配置确认、到达确认和再次启动授权。
- 演示情境折叠到初始任务设置中。执行阶段仅显示自动进度和可选停止操作，最终显示结果；现场维护与异常恢复不再作为演示中必须点击的成功链路。
- 同步概览、产品设计场景、流程、元描述与两份产品说明；技术 Demo 仍处于规划阶段，模拟不代表真实设备自主能力。

验证：状态机脚本 87 项断言通过，覆盖一次提交、自动完成、前置校验、异常、停止和重置。Astro 检查 0 errors / 0 warnings，保留一条既有未使用变量提示；构建生成 22 页，Pagefind 索引 18 页。浏览器确认两套正常流程自动完成，以及取物缺失、交付区占用、工位不可用、校准失败、安全停止和重置；390px 手机视口核对两页无横向溢出。

## 固定轨迹网页技术 Demo（2026-10-13）

将两份产品设计页的技术 Demo 占位替换为可运行的三维组件。场景由 Three.js 渲染，固定轨迹、夹持约束、重力与支撑接触、空间重叠、底盘扫掠和停靠误差由独立计算模型处理。首次进入 Demo 视口时加载三维资源；离开视口或页面不可见时暂停，组件卸载时释放资源。

- HomeAgent：正常送书、交付区占用、书籍掉落三个样例。
- ReTask：正常跨工位上件、迁移路线受阻、停靠位置偏差三个样例。
- 每套 Demo 有机器人本体端、中控端、用户端三个状态框，分别展示任务、状态与反馈；一次提交后自动执行，最后同步完成或异常通知。提供事件记录、模拟执行时间、已验证放置次数与局部计算反馈。
- 运行中锁定样例和速度，允许主动停止；终态可重新运行或选择其他样例。模拟参数、固定轨迹、简化夹持与未连接真实设备的边界在页面注明。
- 修复浏览器测试发现的既有全局浮层关闭错误：对不存在的浮层节点使用可选访问，避免 Demo 点击时抛出空节点异常。

计算检查：新脚本 `node scripts/check-technical-demos.mjs` 的 68 项断言通过；原交互原型 87 项断言仍通过。完整类型检查 0 errors / 0 warnings，保留一条既有提示；构建生成 22 页，Pagefind 索引 18 页。实现与参数说明见 `docs/technical-demos.md`。

浏览器验证：六个样例均得到对应结果，正常流程无需后续点击；三端框同步完成/未完成通知。确认停止、重新运行、样例切换以及站内页面切换后的场景初始化。两页在 390px 宽度下无横向溢出，三端框按手机布局堆叠；恢复默认视口后保存 `docs/screenshots/retask-technical-demo.jpg`，截图包含三维场景与三个完成状态框。修复后的预览不再产生浮层空节点点击错误。
