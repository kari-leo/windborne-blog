# HomeAgent / ReTask 第二轮改版说明

本轮按第二轮待办增量修改，保留概览布局、既有导航、背景、字体与色板。新增的“查看项目文档”位于概览正文的问题定义区域，跳转至全部五份成果卡片；每份文档仍只有一个正文入口。

## 页面与交互

- **项目概览**：同步床边取书故事；计数改为“5 份研究与设计成果”，分类筛选保留。
- **HomeAgent 产品设计**：主场景改为休息时从客厅取书、交付到床边安全区。解释替代办法、价值假设和适用边界。嵌入可点击原型：选择物品与终点 → 确认授权 → 四阶段取送 → 等待用户确认 → 完成。支持物品不在位、交付区占用，以及原阶段重试、取消和转人工。
- **ReTask 产品设计**：嵌入 A 运行 → 请求 B → 前置检查 → 安全退出 → 迁移 → 配置 → 校准 → B 就绪 → 授权运行的原型。缺少字段、切换权限、B 可用性或配置确认时阻止继续；校准失败不能进入运行，恢复后必须重新检查。支持安全停止及重置。
- **关键决策**：在 ToB 转向之后、仓储场景细化之前补制造/仓储/零售服务对比，说明选择标准与可能否定移动方案的条件。未新增市场规模、客户研究结果或 ROI 结论。
- **产品说明与页脚**：删除两份产品说明正文的重复一级标题。两份说明后续按用户要求删除研究与验证计划章节，将商业模式和竞品研究合并至后部；产品定义与任务边界保留。页脚改为简洁版权信息。

## 保留的占位与限制

两个技术 Demo 仍为“规划中”；独立 ReTask 跨工位切换 PRD 页面已删除，不再单独编写；相关内容由产品设计原型与完整产品说明承载。交互原型完全由本地前端状态驱动，未连接机器人、视觉系统、产线或后端，不代表真实部署与已验证需求。刷新、重新进入页面或重置后恢复初始状态，不保存用户数据。

## 产品说明结构调整

ReTask 删除“客户研究与竞品验证计划”，HomeAgent 删除“后续验证计划”。原中部的竞品与替代方案与商业内容合并为末尾第 7 章“商业模式与竞品研究”，两份文档均按商业模式、成本经济性、竞品替代方案、竞争判断四层组织。MVP、技术和风险/产品演进章节前移并连续编号；资料来源仍放在最后。未新增竞品数据或已完成研究结论。

## 最终产品形态调整

- HomeAgent：小型底盘、轻量操作臂与圆润机身，面向家庭通行和轻小物品服务。家庭本地中控为独立机箱，通过本地网络协同；中控负责家庭级权限与任务，本体保留运动执行和独立安全链路。
- ReTask：宽轮距承载底盘、加固安装基座、粗壮工业操作臂与本体控制模块，突出高负载、高刚度设计方向。负载与刚度不是已实现指标，具体规格仍由包裹谱和工程评估确定。
- 两套形态同步用于概览缩略图和产品设计页；说明文档中的本体与中控定义同步更新。全站布局、背景、字体与颜色配置沿用现有版本。
- 最终构建 21 页、类型检查 0 errors / 0 warnings、交互状态机 54 项校验通过。新形态从构建后的 SVG 渲染为图像核对轮廓、机箱分离与标注；本轮浏览器自动连接临时不可用，未将静态图检查表述为新的浏览器验证。
