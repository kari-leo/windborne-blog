# HomeAgent / 迁作 ReTask 网页技术 Demo

两套 Demo 使用简化三维场景、轨迹跟踪和局部物理计算。Three.js 负责渲染，独立 TypeScript 模型负责任务与局部计算。组件进入视口后加载三维模块；页面不可见或 Demo 离开视口时暂停执行，卸载时释放动画帧、观察器、控制器、纹理、材质与几何资源。

## 执行与三端状态

用户在开始时选择样例并提交一次任务，之后自动执行。可主动停止或在终态重新运行；运行中锁定样例与速度。

| 状态框 | 任务 | 运行时状态与反馈 |
|---|---|---|
| 机器人本体端 | 路线跟踪、简化夹持与取放、局部检测 | 当前执行阶段、接触面、轨迹包络、物体高度或异常原因 |
| 中控端 | 编排任务、管理授权范围与工位配置、验证结果 | 当前调度阶段、本体反馈、结果归档或阻止后续执行 |
| 用户端 | 提交取书或跨工位搬运与分类任务 | 待提交、已提交无需继续操作、已收到完成或未完成通知 |

事件记录保留请求、中控指令、本体反馈与通知。三端均为网页内逻辑角色，未连接真实设备或网络通信。

## 六个样例

| 产品 | 样例 | 场景变化 | 结果依据 |
|---|---|---|---|
| HomeAgent | 正常送书 | 客厅取书台到床边交付台 | 释放后计算重力落定，书籍接触指定台面才完成 |
| HomeAgent | 交付区占用 | 交付台上增加占位箱 | 放置空间与箱体重叠，停止放置并保持夹持 |
| HomeAgent | 书籍掉落 | 运输阶段保持力降至 1 N | 0.4 kg 书籍重力约 3.92 N，脱离约束并落地后报告未完成 |
| ReTask | 搬运与分类完成 | A 工位搬运补料，B 工位分类蓝色物品 | A 补料台与 B 蓝色分拣区的接触均验证通过才完成 |
| ReTask | 授权区域内绕障 | 迁移路线固定位置有障碍；B 物品为琥珀色 | 检测底盘扫掠碰撞后暂停，校验局部路线与授权边界，切换并跟踪至 B，投放琥珀色区后完成 |
| ReTask | 分拣目标区满载 | 蓝色分拣区被占满 | A 已完成；B 检查投放空间重叠后停止，保留待分拣物品并通知未完成 |

障碍位置固定，不提供拖动或随机位置。停靠位置偏差样例已移除。对应分类目标不可改投其他类别。

## 计算边界

- 沿折线路段按长度插值。ReTask 的局部路线切换前逐段检查底盘扫掠和完整路线的授权包络；切换从当前机器人位置开始，保持连续运动。局部路线不可用时安全停止。
- 夹取采用简化约束，不验证逆运动学、关节力矩或真实抓取稳定性。
- 局部计算包括重力运动、水平支撑面接触、包围盒空间重叠、底盘路径扫掠和授权边界检查，不是完整机器人动力学仿真。
- 颜色分类读取场景标签，感知输入为几何真值；中控配置不是实际用户习惯学习。
- 所有尺寸、质量、力均为演示参数，不验证真实计算卸载、噪声、负载、刚度或工业安全性能。

## 移动端 Mermaid

图表默认适应容器宽度，容器变化时自动重算。支持缩小、放大、100% 原尺寸和展开查看；放大后通过容器滚动阅读。展开使用原 SVG，避免重复标记 ID，关闭或按 Esc 后恢复页面内视图。组件卸载清理监听与观察器，兼容站内页面切换及缓存恢复。

## 验证入口

`node scripts/check-technical-demos.mjs` 覆盖六个样例、三端通知、停止、物理终态、不同帧率、路线连续性、授权边界、分类与满载。改变障碍、保持力、支撑面或分类标签时，结果随模型输入变化。

既有交互原型检查：`node scripts/check-homeagent-prototypes.mjs`。
