# HomeAgent / ReTask 项目概览：主内容区设计规范

适用页面：`/portfolio/homeagent/`。本方案已实现于 `src/components/homeagent/PortfolioOverview.astro`，概览路由将项目文档集合传入该组件。

## 1. 整体布局与叙事逻辑

页面先提出“机器人应该先为谁创造价值”的问题，再讲述家庭、企业场景与移动方案之间的取舍，最后将所有可阅读作品展开。所有文档在概览正文中各保留一个卡片入口。开场两部分通过完整的问题与决策叙事获得更高的视觉占比，整体布局保持不变。

桌面主内容区由三个纵向层级组成：

```text
项目名称 HomeAgent / ReTask
┌──────────────────────┬──────────────────────┐
│ 01 问题起点           │ 02 方向取舍           │
│ 核心命题、家庭执行缺口 │ HomeAgent → ReTask    │
│ 用户、任务、价值判断   │ 产品化、场景、方案选择 │
└──────────────────────┴──────────────────────┘
─────────────────────────────────────────────
03 项目作品
固定筛选栏：作品类型 / 结果数量
┌──────────────────────┬──────────────────────┐
│ HomeAgent 产品设计    │ ReTask 产品设计       │
├──────────────────────┼──────────────────────┤
│ 关键决策 Case Study   │ 跨工位切换 PRD        │
├──────────────────────┼──────────────────────┤
│ HomeAgent 产品说明    │ ReTask 产品说明       │
└──────────────────────┴──────────────────────┘
```

产品设计卡片在首行，以形态缩略图形成视觉重心。第二行展示方向取舍与功能问题，第三行提供完整产品定义、边界与验证计划。所有卡片均指向独立详情页，不在概览重复长文正文。

问题定义按“为谁解决、从什么任务切入、怎样判断值得做”展开，补充家庭成员、预设取送闭环、替代方案与失败接管。方向取舍以三个具体矛盾展开：家庭通用能力是否构成购买理由、仓储任务为何值得优先探索、移动共享是否优于固定设备或人工支援。每个节点提供判断所面对的代价与开放问题，吸引读者通过关键决策卡片深入阅读；不设置文档内容总结。内容来自既有产品说明与关键决策，不增加未经验证的用户成果或市场结论。

不设置分区阅读导航栏、首屏查看作品按钮、单独的首版边界说明或末尾结论栏。

叙事明确区分家庭愿景与仓储候选方向。跨工位复用仅表述为待验证的价值假设。公开页面不显示 PROJECT STATUS、改版进度、文档编写分工等作者工作说明。

## 2. 布局尺度与 Figma 还原

所有内容宽度继承现有主布局，不改侧栏宽度、页面外边距或全站断点。以下断点针对**主内容容器宽度**，并非浏览器宽度。

| 主内容宽度 | 开场故事 | 作品网格 | 筛选栏 |
|---|---|---|---|
| 大于 44rem | 两列，比例 1.1 : 1，间距 2rem | 两列，间距 1.5rem | 分类靠左，结果数量靠右 |
| 36rem 至 44rem | 纵向排列；方向取舍内部两列 | 两列，间距 1.5rem | 分类靠左，结果数量靠右 |
| 不大于 36rem | 全部纵向排列 | 单列，间距 1rem | 分类与数量允许换行；按钮最小高度 2.75rem |

当前全站根字号在桌面为 16px、窄屏为 14px，因此规格使用 rem。不要在概览组件中重设根字号。以 1280px 视口为例，现有布局提供 864px 主内容宽度，作品卡片为 420px × 360px；390px 视口提供 362px 主内容宽度，卡片为 362px × 315px。内容变长时高度允许增长，避免截断。

Figma 组件建议：

- `Overview / Main`：纵向 Auto Layout，宽度 Fill container；沿用网站既有内容框架。
- `Opening / Story`：水平 Auto Layout，左侧 1.1 份、右侧 1 份；间距 32px。窄版切为纵向。
- `Direction / Block`：垂直 Auto Layout，标签、结论、依据依次排列；以 2px 竖线辅助分组。桌面故事两列之间使用 1px 分隔线。
- `Works / Toolbar`：分类靠左、数量靠右，空间不足时换行；交互原型设置滚动固定。不提供关键词搜索。
- `Works / Grid`：两列等宽，横纵间距均为 24px；窄版一列、间距 14px（1rem）。
- `Work / Card`：纵向 Auto Layout，缩略图区固定 10rem，正文区 Fill；最小总高 22.5rem，行动入口贴底。

## 3. 模块内容与全部文档入口

| 排序 | 卡片 | 内容表达 | 文档链接 |
|---|---|---|---|
| 1 | HomeAgent｜家庭物理执行终端 | 家庭取送形态、场景与任务委托界面 | `/portfolio/homeagent/homeagent-showcase/` |
| 2 | ReTask｜仓储移动操作系统 | 包裹操作、两工位切换与现场配置 | `/portfolio/homeagent/retask-showcase/` |
| 3 | 从 HomeAgent 到 ReTask | 四次取舍：家庭、企业任务、3PL、具体工位 | `/portfolio/homeagent/decision-case-study/` |
| 4 | ReTask｜跨工位切换与重新配置 | 任务、技能与现场配置的功能问题；标注内容待完善 | `/portfolio/homeagent/retask-reconfiguration-prd/` |
| 5 | HomeAgent｜产品说明 | 家庭需求、候选任务、权限与安全边界、验证 | `/portfolio/homeagent/home-agent/` |
| 6 | ReTask｜产品说明 | 3PL 客户、系统边界、工位复用经济性 | `/portfolio/homeagent/retask/` |

每张卡片只有一个整卡链接，内部名称与行动文案构成同一操作，避免嵌套按钮及重复键盘焦点。每份文档在概览正文中只链接一次，开场没有独立的文档链接。类型标签明确说明产物性质；产品设计标注“概念方案”，专项 PRD 标注“内容待完善”。

产品设计预览复用现有代码生成的结构示意；决策预览使用四个简洁节点；PRD 使用工位 A / B 关系；说明文档使用产品名与场景、任务、系统三个层级。它们均为概念导航图，不暗示真实部署或已完成验证。

概览底部不设置 Demo 栏；进入对应产品展示页后仍可查看 Demo 占位区块。

概览卡片由项目文档集合生成。未来新增文档也会自动出现，未配置专属预览时使用通用文档卡片，避免入口遗漏。

## 4. 关键交互与状态

| 操作 / 状态 | 行为与视觉反馈 |
|---|---|
| 初始 | 全部选中，显示 6 项作品 |
| 分类 | 全部 / 产品设计 / 关键决策 / 产品说明 / PRD；单选，原位置不变；选中使用既有按钮底色、主色文字、600 字重与边框 |
| 分类结果 | 保持原卡片相对顺序；结果显示“匹配数 / 总数 项作品” |
| 某分类暂无作品 | 保留工具栏，展示“该类型暂无作品”和“查看全部作品”；恢复后聚焦“全部”筛选按钮 |
| 卡片 hover | 160ms ease；边框转既有主色，上移 2px，入口箭头右移 3px；无阴影或放大 |
| 卡片 / 按钮键盘焦点 | 2px 主色外轮廓；卡片偏移 3px，普通链接和按钮偏移 4px |
| 既有锚点兼容 | 保留问题、取舍、作品区的深链接目标与 5.5rem 顶部偏移；页面不显示分区跳转按钮 |
| 滚动 | 工具栏 `sticky`，距页面顶部 3.5rem，与既有导航高度对应；只在作品区域内固定 |
| 减少动态效果 | 系统开启 reduced motion 时，移除卡片位移、箭头位移与新增过渡 |
| 无 JavaScript | 六个文档链接仍可阅读；不展示无效筛选工具栏 |
| 从详情返回 | 重置为全部作品，筛选重新可用；适配既有 Swup 页面切换 |

筛选为语义化 button，使用 `aria-pressed` 表示选中；结果数量使用 polite live region；概念缩略图不重复朗读卡片标题。所有入口支持 Tab、Enter。窄版筛选目标最小高度 2.75rem，沿用全站根字号换算。

## 5. 与现有网站的适配

整体背景、固定左侧栏、顶部导航、移动项目导航、字体定义、色板配置均保持本轮开始时的状态。组件仅增加主内容区作用域样式；主布局没有重定义。

| 作用 | 既有 token |
|---|---|
| 页面 / 固定筛选栏背景 | `--page-bg` |
| 卡片表面 | `--card-bg` |
| 标题及重点文字 | `--deep-text` |
| 描述、辅助信息 | `--btn-content` |
| 预览与选中分类底色 | `--btn-regular-bg` |
| 非选中分类 hover | `--btn-plain-bg-hover` |
| 边框与分隔线 | `--line-color` |
| 链接、序号、状态反馈、焦点 | `--primary` |

不写死新的品牌色。主色用于卡片入口与状态反馈。概览中的两款机器人缩略图均跟随既有主色，避免引入第二套产品色系。浅色、深色状态由全站 token 控制，无独立主题开关。

## 6. 验证范围

已核对桌面、平板与手机窄屏的文字换行和横向溢出。最终构建成功生成 22 个页面，Pagefind 索引更新成功；六份文档在概览正文中均保留唯一入口。类型筛选与详情导航沿用此前验证过的行为。

构建产物已确认：概览正文无关键词输入框、无 Demo 栏、无分区阅读导航、无首屏查看作品按钮、无首版边界独立说明、无能力总结与末尾结论栏；三个取舍问题完整呈现。全部六份文档均可通过卡片访问，每份恰好一个链接。既有侧栏与全局样式配置沿用此前版本。

全站类型检查仍有三处既有错误，位于 Navbar、About、Archive；本次未新增类型错误。
